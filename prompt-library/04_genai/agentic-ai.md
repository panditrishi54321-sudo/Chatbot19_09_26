# Agentic AI Prompt

Explain or design an Agentic AI workflow for SkillSpring.

Cover:
- goal
- planning
- tool selection
- tool execution
- observation
- state/memory
- verification
- final response

Use SkillSpring examples such as:
- retrieving student/course information;
- generating a learning plan;
- checking learning progress;
- selecting an appropriate learning resource.

Clearly distinguish a normal chatbot response from an agent that can decide and execute tool calls.

Do not claim a capability exists in SkillSpring unless it is implemented.
