# AI Memory Prompt

Explain AI memory in the context of SkillSpring.

Cover:
- conversation history
- short-term context
- persistent application data
- retrieval
- user preferences
- privacy considerations

Clarify that sending browser conversation history to an LLM is not automatically the same as having persistent model memory.

For SkillSpring:
- student records belong to application/database data;
- chat history is conversation context;
- persistent memory must have an explicit storage and privacy design.

Do not expose sensitive data unnecessarily.
