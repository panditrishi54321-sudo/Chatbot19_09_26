# RAG Prompt

Explain Retrieval-Augmented Generation (RAG) using SkillSpring.

Flow:
User question
-> retrieval/query logic
-> relevant application data
-> context
-> LLM
-> grounded response

Distinguish:
- database lookup
- retrieval
- context injection
- generation
- fine-tuning
- model training

For SkillSpring, use actual available student/course/application context where supported.

Do not invent retrieved records.
If no relevant context is found, say so.
