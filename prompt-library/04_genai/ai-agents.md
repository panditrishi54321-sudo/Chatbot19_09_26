# AI Agents Prompt

Teach AI agents using SkillSpring as the practical example.

Explain:
- model
- instructions
- tools
- context
- memory/state
- planning
- action
- observation
- validation
- final answer

Use simple diagrams and beginner-friendly examples.

When discussing SkillSpring, distinguish:
- currently implemented behaviour
- proposed future behaviour

Never describe a proposed agent capability as already implemented.
