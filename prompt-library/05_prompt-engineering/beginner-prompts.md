# Beginner Prompt Templates

## Explain a concept
Explain [TOPIC] in simple beginner-friendly language. Give:
1. definition
2. everyday analogy
3. one technical example
4. common mistake
5. short practice question

## Explain my code
Explain this code line by line. Do not change the code. First explain what it currently does, then explain why each important line exists.

## Fix an error
Here is my error and code. First identify the likely root cause. Then show the smallest fix. Finally give the exact command/test I should run.

## Teach through my project
Explain [CONCEPT] using my SkillSpring project as the example. Clearly distinguish what already exists from what would be a proposed enhancement.
