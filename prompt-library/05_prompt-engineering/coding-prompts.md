# Coding Prompt Templates

## Minimal change
Modify only the required part of the existing code. Preserve function names, route names, IDs, classes and surrounding logic unless a change is required.

## Complete method
Complete the existing method without replacing the class or project structure. Reuse existing waits/helpers/utilities and add fallback behaviour only where necessary.

## Code review
Review the supplied code for bugs, maintainability, error handling and edge cases. Do not rewrite it automatically. List findings first, then provide targeted corrections.

## Test implementation
Create tests based on the existing application flow and contracts. Do not invent APIs, database fields or UI selectors.
