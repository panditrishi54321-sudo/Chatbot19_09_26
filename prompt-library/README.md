# SkillSpring Prompt Engineering Library

This folder contains reusable prompts, project context, debugging prompts,
feature-development prompts, GenAI learning prompts, and prompt-engineering notes.

## Structure

### 01 Project
Prompts related to the SkillSpring project architecture and development rules.

### 02 Debugging
Prompts for debugging Flask, JavaScript, API and chatbot issues.

### 03 Features
Prompts used to build and improve SkillSpring features.

### 04 GenAI
Learning and implementation prompts related to Generative AI, LLMs,
RAG, AI Agents, Agentic AI, Tool Calling, MCP and AI Memory.

### 05 Prompt Engineering
Experiments and reusable prompt-engineering techniques.

### 06 History
Important previous prompts, improvements and lessons learned.

## Prompt Learning Method

For important prompts, maintain:

1. Original Prompt
2. Context
3. Constraints
4. AI Response
5. Problem with the Response
6. Improved Prompt
7. Final Result
8. What I Learned
9. Reusable Prompt Template
