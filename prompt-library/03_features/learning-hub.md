# Learning Hub Feature Prompt

Improve the SkillSpring Learning Hub while preserving the existing Flask application.

Learning Hub should support:
- learning journey
- current chapter
- progress indicator
- learning streak
- projects progress
- recently viewed content
- chapter search/filtering
- practical labs
- weekly notes
- AI Tutor access

Design:
- professional EdTech appearance
- strong typography
- responsive layout
- accessible controls
- consistent SkillSpring branding
- no unnecessary external dependencies

Before changing code:
- inspect the existing Learning Hub template;
- inspect its JavaScript;
- inspect the Flask route/data source;
- preserve existing IDs/classes used by JavaScript.
