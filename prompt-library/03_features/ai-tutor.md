# AI Tutor Feature Prompt

Build or modify the SkillSpring AI Tutor without breaking the existing chatbot.

Requirements:
- learner-friendly interface
- clear current chapter/topic context
- conversation history
- Send button
- Enter to send
- Shift+Enter for a new line
- Clear Chat
- Help & Suggestions
- graceful loading state
- graceful error state
- readable Markdown/code responses
- responsive layout

AI behaviour:
- teach rather than simply provide answers;
- explain concepts in simple language;
- use examples;
- adapt to beginner/intermediate context when available;
- use SkillSpring context when relevant;
- never invent database records.

Preserve existing API contracts and UI functionality.
